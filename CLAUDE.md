# Nexus

## Design Context

This project has captured design context via `/impeccable init`:

- **[PRODUCT.md](PRODUCT.md)** - register (product), users, purpose, brand personality, anti-references, and design principles. Nexus is a general social-discovery app (not romance-only) with two flavors (`nexus` general, `mec` campus-gated), a playful/energetic and BeReal-style authentic personality, and safety (Safety Center, meetup safety, crisis helplines) treated as first-class product surface.
- **[DESIGN.md](DESIGN.md)** - the visual system as it actually exists in the Flutter app: colors, typography, elevation, and components, under the north star "Constellation Social." Read this before adding or changing UI so new screens stay on-brand (e.g. the Mode Signal Rule: each relationship mode owns one accent color across nav, chat, and filters).

Any `/impeccable` command (`critique`, `polish`, `audit`, `craft`, etc.) reads both files automatically before doing design work.
